Статусы локального сервера и Dolphin.

Профили Dolphin

Профиль — отдельная браузерная сессия. Вход в YouTube выполняется один раз вручную в нужном профиле.

Создать профиль

Профиль создаётся в Dolphin через актуальный fingerprint, полученный из его API.

Аккаунты YouTube

Каждый аккаунт связан с отдельным профилем Dolphin. Вход и подтверждение 2FA выполняются вручную в открытом профиле; панель не хранит пароли или коды.

Пакетные проверки

Проверки распределяются по общему лимиту потоков и не выполняют действий в канале.

Новая задача загрузки

Создаёт задание для выбранного профиля. При запуске задача открывает профиль и отправляет файл в форму YouTube Studio; публикация остаётся на проверке.

Добавить свои видео

Файл можно скопировать в локальную библиотеку или добавить по существующему пути. Перед добавлением Creator Flow проверит формат через FFprobe.
