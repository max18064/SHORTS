# Creator Flow

Локальная панель для планирования публикаций собственных коротких видео: библиотека, очередь задач, шаблоны метаданных, журнал обработки и аналитика.

## Запуск

Запустите `npm start` и откройте `http://localhost:3030`. Сервер отдаёт панель и API очереди.

Проверка API: `npm test`.

## Интеграции

Секреты для внешних сервисов хранятся только локально в `.env` и не добавляются в Git.

`DOLPHIN_AUTOMATION=1` запрашивает у Dolphin адрес автоматизации при старте профиля; отключается значением `0`.

Генератор видео намеренно не входит в продукт. Обработка применяется только к добавленным исходным файлам.

## Ручной вход в YouTube

Creator Flow не принимает, не хранит и не отображает логины, пароли или 2FA-коды YouTube. Для новой задачи профиль Dolphin открывает YouTube Studio; если нужна авторизация, интерфейс показывает статус `manual-login-required`. Пользователь завершает вход в окне профиля и нажимает «Продолжить» в очереди.

## Текущий API

- `GET /api/health` — состояние локального Dolphin API;
- `GET /api/profiles` — профили Dolphin;
- `POST /api/profiles/:id/start` и `POST /api/profiles/:id/stop` — управление профилем;
- `GET /api/tasks` — очередь;
- `GET /api/logs` — журнал запусков и ошибок;
- `POST /api/tasks` — создать задачу;
- `POST /api/tasks/:id/run` — запустить профиль для задачи;
- `POST /api/tasks/:id/cancel` — отменить задачу.
- Планировщик автоматически подхватывает задачи с наступившим `scheduledAt` и запускает профиль Dolphin.
- `GET /api/proxies` — список добавленных прокси без отображения паролей;
- `POST /api/proxies/import` — импорт текстового списка прокси.
- `GET /api/videos` и `GET /api/videos/stats` — реестр опубликованных роликов и агрегаты;
- `POST /api/videos` — добавить публикацию в реестр;
- `PATCH /api/videos/:id/stats` — обновить статистику и статус доступности.
- `GET /api/uniqueizer/health` — проверка доступности FFmpeg для обработки видео.
- `POST /api/uniqueizer/render` — обработка собственного ролика с опциональным PNG-оверлеем.
