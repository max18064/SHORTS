# Creator Flow

Локальная панель управления собственным видеоконтентом через профили Dolphin Anty и YouTube Studio. По умолчанию веб-панель слушает только `127.0.0.1`. Это не генератор видео: в приложение добавляются уже готовые файлы, а затем для них создаются задачи обработки, оформления канала, загрузки и чтения статистики.

## Что реализовано

- Список профилей Dolphin, запуск и остановка профиля через настроенный Dolphin API.
- Создание папок и новых профилей Dolphin из панели. Перед созданием профиль получает целостный fingerprint напрямую из настроенного API Dolphin; пустые или вымышленные отпечатки не используются.
- Проверка состояния YouTube-канала в уже авторизованном профиле и синхронизация списка роликов из YouTube Studio. В интерфейсе показываются только данные последней реальной синхронизации; демонстрационные метрики и тестовые ролики не используются.
- Пакетная синхронизация Studio для выбранного набора профилей: профили распределяются по общему пулу, а прогресс, ошибки и требование ручного входа видны в панели.
- Одиночная и пакетная проверка YouTube-профилей с сохраняемым безопасным результатом: статус, название канала, адрес Studio и время проверки. Пакетная проверка использует тот же общий пул потоков.
- Ручная первичная авторизация: Creator Flow открывает YouTube Studio внутри выбранного профиля Dolphin, пользователь входит в аккаунт в этом окне, после чего продолжает задачу из панели.
- Библиотека видео: добавление файла по локальному пути или загрузка файла в локальную библиотеку с проверкой через `ffprobe`.
- Обработка собственных видео через FFmpeg: перекодирование, удаление метаданных и опциональный PNG-оверлей; результат добавляется в библиотеку.
- Пакетная обработка собственных материалов: до 50 явно выбранных исходников, один отдельный MP4-результат на каждый исходник, сохранённые статусы, восстановление после перезапуска и отдельный лимит FFmpeg в 1–3 потока.
- Очередь задач загрузки с названием, описанием, тегами, профилем и временем запуска. Пакетная очередь создаёт задания сразу для нескольких профилей и по выбору запускает их автоматически с соблюдением лимита потоков.
- Одиночное и пакетное оформление каналов: имя, описание, ссылки, аватар и баннер. Один пакет создаёт отдельную задачу для каждого выбранного профиля; в имени и описании поддерживаются шаблоны `{index}` и `{profileId}`. Изменения применяются только после явного создания и запуска задачи.
- Общий пул операций для загрузок, чтения Studio и задач канала. В панели доступны значения `1`, `3`, `5`, `10` и `20`; на одном профиле одновременно выполняется только одна операция.
- Локальный журнал задач, список локально импортированных прокси и настройки пула. Пароли прокси не возвращаются в интерфейс или API.

## Важные ограничения работы

- Creator Flow не принимает, не хранит и не показывает логины, пароли или 2FA-коды YouTube. Вход выполняется вручную в окне соответствующего профиля Dolphin.
- Задача загрузки заполняет форму ролика в YouTube Studio и останавливается в статусе `awaiting-review`. Финальная кнопка публикации не нажимается автоматически: перед публикацией пользователь проверяет ролик и выполняет её в Studio.
- Реальные данные Studio появляются только после успешной ручной авторизации профиля и запуска проверки или синхронизации. Пустой список означает, что Studio не вернула роликов для выбранного профиля, а не подменяется примерами.
- Пакетная обработка предназначена для явно добавленных собственных исходников: один выбранный файл даёт один выходной MP4. Лимит одного пакета — 50 исходников, а FFmpeg использует от 1 до 3 параллельных процессов; конвейер не создаёт серию копий одного ролика.
- Создание профиля и папки происходит только после нажатия соответствующей кнопки в панели; эти операции не запускаются фоново.
- Максимальное число параллельных операций ограничивает весь процесс, а не каждый тип задач отдельно. Для 20 профилей можно выбрать до 20 потоков, но практическое значение нужно выбирать по мощности компьютера и пропускной способности сети.
- Создание видео в продукт намеренно не входит: обработка работает только с исходными файлами, добавленными пользователем.
- Сервер по умолчанию привязан к `127.0.0.1`. Не меняйте `CREATOR_FLOW_HOST` на сетевой или публичный интерфейс без отдельного контура аутентификации и защиты доступа.

## Быстрый запуск

1. Установите зависимости:

   ```powershell
   npm install
   ```

2. Скопируйте шаблон настроек и заполните его локально:

   ```powershell
   Copy-Item .env.example .env
   ```

   В `.env` укажите токен Dolphin в `DOLPHIN_API_TOKEN`. Для функций чтения Studio, загрузки в форму и оформления канала оставьте `DOLPHIN_AUTOMATION=1`; также должен быть доступен локальный Dolphin API из `DOLPHIN_LOCAL_API`. Оставьте `CREATOR_FLOW_HOST=127.0.0.1`, чтобы панель была доступна только на этом компьютере.

   Для обработки роликов установите FFmpeg и при необходимости укажите полный путь к `ffmpeg.exe` в `FFMPEG_PATH`.

3. Запустите панель:

   ```powershell
   npm start
   ```

4. Откройте `http://127.0.0.1:3030/`.

Локальный файл `.env`, состояние панели и загруженные в библиотеку файлы не должны добавляться в Git.

## Базовый рабочий сценарий

1. Откройте страницу «Профили» или «Аккаунты» и убедитесь, что Dolphin возвращает нужный профиль. При необходимости создайте папку и профиль на странице «Профили».
2. Запустите проверку YouTube. Если профиль ещё не авторизован, откройте ручную сессию, завершите первичный вход непосредственно в окне Dolphin и вернитесь в панель. Это требуется отдельно для каждого используемого YouTube-профиля.
3. Добавьте собственный ролик в «Библиотеку» и при необходимости обработайте его на странице «Обработка».
4. Создайте задачу в «Очереди» для одного профиля или пакет для нескольких профилей. Для автоматического старта пакета включите соответствующий переключатель; задачи будут дренироваться по доступным потокам.
5. После статуса `awaiting-review` проверьте загруженный черновик в YouTube Studio и публикуйте его вручную.
6. Для статистики запустите синхронизацию Studio одного профиля или пакетную синхронизацию всех профилей — данные и ход пакета отобразятся в «Аналитике».

## Проверка

```powershell
npm test
```

Тест запускается с изолированным состоянием и не изменяет рабочую локальную очередь, библиотеку или настройки пользователя.

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `DOLPHIN_API_TOKEN` | локально сохранённый токен доступа к Dolphin API |
| `DOLPHIN_API_BASE` | базовый адрес Dolphin API |
| `DOLPHIN_LOCAL_API` | адрес локального API установленного Dolphin |
| `DOLPHIN_AUTOMATION` | `1` для запроса адреса автоматизации профиля, `0` для запуска без него |
| `FFMPEG_PATH` | путь к `ffmpeg` или `ffmpeg.exe` |
| `PORT` | порт веб-панели, по умолчанию `3030` |
| `CREATOR_FLOW_HOST` | интерфейс веб-панели; по умолчанию и для локального запуска `127.0.0.1` |
